# Threat Hunting

This section documents hypothesis-driven threat hunting and investigation activities conducted using external blue-team training environments and supporting security telemetry.

## Objectives

- Develop hypothesis-driven threat hunting methodology
- Investigate attacker behaviour using available telemetry
- Identify relevant indicators and behavioural evidence
- Map findings to MITRE ATT&CK techniques
- Identify detection opportunities
- Connect threat hunting findings with the existing Splunk detection engineering work

## Evidence Sources

Threat hunting cases will be documented based on the specific telemetry and artifacts provided by the investigation environment.
